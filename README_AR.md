# ProTech Quotes & Contracts v2.0.0-beta.2

تطبيق مستقل على Windows 10/11 x64 لإدارة العروض والعقود والعملاء والمشاريع والتسعير والمخزون والدفعات والتقارير.

## التثبيت
شغّل Setup.exe، واختر اختصار سطح المكتب اختياريًا. لا يتطلب تثبيت Python ولا صلاحيات مسؤول.

**الإصدار v2 منفصل عن v1.1.0**: لا يستبدل البرنامج القديم ولا ينقل بياناته تلقائيًا. يبدأ الإصدار الجديد بقاعدة بيانات فارغة في:
%LOCALAPPDATA%\ProTech\QuotesContractsV2

لا يتضمن المثبت بيانات عملاء أو ملفات تجريبية، وتبقى البيانات عند إلغاء تثبيت البرنامج.

## الميزات
- قوالب جاهزة لعروض الأسعار والعقود يمكن تعديلها وحفظ نسخة جديدة.
- إدارة العملاء والمشاريع والمقاسات والزيارات والتسعير والإنتاج والتركيب والمخزون.
- دفعات وعقود وكشوف حساب وسندات قبض تجارية غير ضريبية.
- تقارير PDF عربية A4 وWord DOCX وExcel XLSX وCSV.
- المعاينة والطباعة بعد موافقة المستخدم، وأزرار الرجوع والتقدم والخروج.
- استعادة آخر صفحة ومشروع بعد إعادة التشغيل، ونسخ ZIP موثقة SHA256 مع استعادة إلى مجلد جديد.
